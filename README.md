# P Smart Wallet 888

เวอร์ชันปัจจุบัน **V1.3.3** ดูรายละเอียดแต่ละรอบได้จากปุ่มประวัติการอัปเดตใน MENU

เว็บแอปบันทึกรายรับ-รายจ่ายส่วนตัว สำหรับนักเรียน นักศึกษา และวัยเริ่มทำงาน
เน้นบันทึกไว ดูสรุปเข้าใจง่าย และเก็บข้อมูลไว้ในเครื่องผู้ใช้เท่านั้น

## วิธีเปิดใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ **ห้ามดับเบิลคลิกไฟล์ `index.html` โดยตรง** เพราะเบราว์เซอร์
บล็อก ES modules บน `file://` และระบบเข้ารหัสรหัสผ่านต้องการ secure context

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ถ้าจะเผยแพร่จริง ใช้ GitHub Pages หรือ static host อะไรก็ได้ที่เสิร์ฟผ่าน https

## หน้าจอหลัก

| หน้า | ทำอะไร |
|---|---|
| โฮม | หมวดที่ปักหมุดไว้สำหรับบันทึกด่วน ภาพรวมเดือนนี้ ยอดคงเหลือสะสม รายการล่าสุด สถานะงบประมาณ รายการฟีเจอร์ และข้อมูลผู้ใช้ |
| บันทึก | เลือกรายรับ/รายจ่าย กรอกจำนวนเงิน เลือกหมวดหมู่ ใส่โน้ต เลือกวันที่ (ย้อนหลังได้ 60 วัน) |
| สถิติ | สลับมุมมอง วัน/สัปดาห์/เดือน/ปี พร้อมกราฟวงกลม 3 มิติ ยอดคงเหลือ และ breakdown ตามหมวดหมู่ |
| วางแผน | ตั้งงบประมาณรายเดือน และตั้งเป้าหมายการออมเงิน |

## ระบบงบประมาณและการแจ้งเตือน

ตั้งเพดานการใช้จ่ายได้ทั้งรายหมวด และงบรวมทั้งเดือน แยกตามกระเป๋า
งบเป็นแบบต่อเดือนและใช้ซ้ำทุกเดือน ไม่ต้องตั้งใหม่

ระดับการเตือนมีสามขั้น

| ระดับ | เมื่อไร | สี |
|---|---|---|
| ยังอยู่ในงบ | ต่ำกว่า 70% | เขียว |
| ใกล้เกินงบ | 70% ถึงต่ำกว่า 100% | เหลือง |
| เกินงบแล้ว | ตั้งแต่ 100% ขึ้นไป | แดง |

แจ้งเตือนสี่จุด คือ ข้อความใต้ช่องจำนวนเงินตอนเลือกหมวด (เห็นก่อนจ่ายจริง),
toast ตอนบันทึกแล้วข้ามระดับ, การ์ดสรุปในหน้าโฮม และแถบเต็มในหน้าวางแผน

toast จะขึ้น**เฉพาะตอนข้ามระดับขึ้นไปเท่านั้น** บันทึกซ้ำในระดับเดิมจะไม่เตือนอีก
เพื่อไม่ให้ผู้ใช้ชินจนเลิกสนใจ ถ้าลบรายการจนลดลงต่ำกว่าเกณฑ์ ระบบจะรีเซ็ตให้เตือนใหม่ได้

การแจ้งเตือนทำงานในแอปเท่านั้น ไม่มี notification ระดับระบบปฏิบัติการ เพราะเว็บที่ไม่มีเซิร์ฟเวอร์
ปลุกหน้าที่ปิดอยู่ไม่ได้

## การเก็บข้อมูล

ข้อมูลถูกเก็บสองที่ และไม่มีการส่งออกไปที่เซิร์ฟเวอร์ใดเลย

1. **เบราว์เซอร์ของเครื่องนี้** เป็นแหล่งข้อมูลหลัก บันทึกทันทีทุกครั้ง ใช้งานได้ทุกเบราว์เซอร์
   และทำงานแบบออฟไลน์
2. **ไฟล์ CSV ในเครื่อง** เป็นชั้นเก็บประวัติ เปิดอ่านได้ด้วย Excel และ Google Sheets

บนเดสก์ท็อป Chrome และ Edge แอปเขียนไฟล์ให้อัตโนมัติหลังผู้ใช้เลือกไฟล์ครั้งแรก
บนเบราว์เซอร์อื่นและบนมือถือ ใช้ปุ่มดาวน์โหลดและนำเข้าแทน เพราะ File System Access API
ยังไม่รองรับ

### เรื่องรหัสผ่าน

**กรอกแค่ชื่อผู้ใช้ก็เริ่มใช้ได้เลย ไม่ต้องมีรหัสผ่าน** ตามที่ blueprint กำหนด
รหัสผ่านเป็นตัวเลือกเสริมที่ติ๊กเปิดได้ตอนสร้างบัญชี

ถ้าเลือกตั้ง รหัสผ่านจะถูกเก็บเป็น hash ด้วย PBKDF2 (SHA-256, 150,000 รอบ) ผ่าน WebCrypto
ไม่มีการเก็บรหัสผ่านเป็นข้อความล้วน

**รหัสผ่านนี้ใช้แยกผู้ใช้บนเครื่องเดียวกัน ไม่ใช่ระบบความปลอดภัย** ไฟล์ CSV ไม่ได้เข้ารหัส
ใครที่เข้าถึงเครื่องได้ก็เปิดอ่านผ่าน Excel ได้โดยไม่ต้องผ่านแอป
ประโยชน์จริงคือกรณีที่หลายคนใช้เครื่องเดียวกันแล้วบังเอิญตั้งชื่อผู้ใช้ซ้ำกัน

ตอนเข้าใช้งาน ถ้าชื่อนั้นไม่มีบัญชีไหนตั้งรหัสผ่านไว้ จะเข้าได้ทันที
ถ้ามีบัญชีที่ตั้งรหัสไว้ ระบบจะขอรหัสผ่าน และถ้าเว้นว่างจะเข้าบัญชีที่ไม่มีรหัสผ่านแทน

ไม่มีระบบรีเซ็ตรหัสผ่าน แต่ตั้งคำใบ้ได้ ซึ่งจะแสดงเมื่อกรอกผิดครบ 3 ครั้ง
และถ้าลืมจริงๆ ยังกู้ข้อมูลได้ด้วยการสร้างบัญชีใหม่แล้วนำเข้าไฟล์ CSV ที่เคยบันทึกไว้

### ราคาต่อหน่วย จำนวน และการปักหมุด

เปิด MENU แล้วกดจัดการหมวดหมู่ เพื่อตั้งค่าสามอย่างของแต่ละหมวด

- **ราคาต่อหน่วย** ตั้งไว้ครั้งเดียว เช่น ก๋วยเตี๋ยว 50 บาท ครั้งต่อไปที่กดหมวดนี้ในหน้าบันทึก
  ช่องจำนวนเงินจะเติมให้เอง และยังพิมพ์ทับได้เสมอ ตั้งได้ทั้งหมวดมาตรฐานและหมวดที่สร้างเอง
- **จำนวน** ในหน้าบันทึกมีช่องจำนวนใต้ช่องเงิน ปรับได้ทั้งพิมพ์ตัวเลขและกดปุ่มเพิ่มลด
  ซื้อ 3 ชามได้ยอดรวม 150 อัตโนมัติ ยอดที่เก็บลงข้อมูลเป็นยอดรวมเสมอ
  ส่วนจำนวนหน่วยถูกเก็บไว้ด้วย แถวรายการจึงแสดง `× 3` ให้เห็น
- **ปักหมุด** หมวดที่ปักหมุดจะขึ้นบนหน้าโฮม แยกเป็นแถวรายรับและแถวรายจ่าย
  กดชิปครั้งเดียวจะไปหน้าบันทึกพร้อมประเภท หมวด และราคาที่กรอกไว้ให้แล้ว

ถ้ายังไม่ได้ปักหมุดอะไรเลย การ์ดบนหน้าโฮมจะมีปุ่มไปหน้าบันทึกและปุ่มจัดการหมวดหมู่แทน

### หมวดหมู่ที่ตั้งเอง

กด "อื่นๆ" แล้วพิมพ์ชื่อหมวดได้เลย มีช่องติ๊ก "บันทึกเป็นหมวดใหม่" ที่เปิดไว้ให้
ถ้าติ๊กไว้หมวดนั้นจะกลายเป็นปุ่มลัดในครั้งต่อไป ถ้าไม่ติ๊กก็ใช้แค่ครั้งเดียว
ระหว่างพิมพ์ระบบจะเสนอหมวดที่เคยสร้างไว้ให้กดเลือกได้

ตอนลบหมวด ระบบจะบอกว่ามีกี่รายการที่ใช้หมวดนั้นอยู่ แล้วเปลี่ยนรายการเหล่านั้น
จาก "น้ำมัน" เป็น "อื่นๆ (น้ำมัน)" ประวัติจึงไม่เสียความหมาย และงบประมาณของหมวดนั้นก็ย้ายตามไปด้วย

### แผงคู่มือ ข้อมูลสำหรับอาจารย์ และประวัติการอัปเดต

ใน MENU มีสามแผงอ่านอย่างเดียว

- **คู่มือการใช้งาน** สำหรับผู้ใช้จริง บอกวิธีบันทึก วิธีอ่านสรุป วิธีตั้งงบ วิธีเก็บไฟล์
  และวิธีย้ายข้อมูลไปเครื่องอื่น
- **ข้อมูลสำหรับอาจารย์** ขึ้นต้นด้วยหัวข้อว่าเว็บแอปนี้พัฒนาด้วย Claude AI
  แล้วอธิบายฟีเจอร์ตามโจทย์พร้อมเหตุผลที่เลือกทำแบบนั้น ฟีเจอร์เสริมที่เพิ่มเข้ามา
  และข้อจำกัดที่รู้ตัวและยอมรับ
- **ประวัติการอัปเดต** บอกว่าแต่ละเวอร์ชันเพิ่ม ปรับ หรือลบอะไรไปบ้าง เปิดจากปุ่มในเมนู
  หรือกดที่ป้ายเลขเวอร์ชันข้างหัวข้อ MENU

เลขเวอร์ชันอ่านว่า `V N1.N2.N3` โดย N2 คือเฟส หนึ่งเฟสเท่ากับหนึ่งอัปเดต
N3 คืออัปเดตย่อยในเฟสนั้นซึ่งเริ่มที่ 0 เฟสที่แยกเป็น A และ B จึงนับเป็นอัปเดตย่อยสองครั้ง
ส่วน N1 จะเพิ่มขึ้นเมื่อ N2 จะเกิน 5 แล้วรีเซ็ต N2 กลับเป็น 1

### บัญชีและกระเป๋า

หนึ่งบัญชีมีได้หลายกระเป๋า สลับได้จากปุ่ม MENU มุมขวาบน ข้อมูลของแต่ละกระเป๋าแยกกัน
เหมาะกับการแยกเงินใช้ประจำวันออกจากเงินเก็บก้อนอื่น

ถ้าบัญชีไม่มีกระเป๋าเลย เช่นนำเข้าไฟล์ที่ไม่มีข้อมูลกระเป๋าติดมา หน้าโฮมจะแจ้งและให้กดสร้าง
ส่วนแท็บอื่นจะพากลับมาหน้าโฮมจนกว่าจะมีกระเป๋า

### การนำเข้าและการรวมข้อมูล

- ไฟล์เพิ่มคอลัมน์ `cost`, `quantity` และ `pinned` ต่อท้ายตั้งแต่ V1.3.3 ไฟล์ที่บันทึกไว้ก่อนหน้านั้นยังนำเข้าได้ตามปกติ
- รายการที่ id ซ้ำกันใช้กฎ last-write-wins ตาม `updatedAt` ถ้าเวลาเท่ากันให้ของในเครื่องชนะ
- การลบเป็นแบบ soft delete รายการที่ลบไปแล้วจะไม่ฟื้นกลับมาเมื่อนำเข้าไฟล์เก่า
- แถวที่ข้อมูลไม่ถูกต้องจะถูกข้ามพร้อมบอกเหตุผล ไม่ทำให้การนำเข้าทั้งไฟล์ล้มเหลว
- รายการที่ไม่มีกระเป๋าต้นทางจะถูกย้ายไปกระเป๋าชื่อ "รายการที่กู้คืน" แทนที่จะหายไปเงียบๆ

```
js/docs.js          แผงคู่มือการใช้งานและแผงข้อมูลสำหรับอาจารย์

js/csv.js           อ่านและเขียนไฟล์ CSV

js/validate.js      กฎ validation ที่ใช้ร่วมกันทุกหน้า
js/format.js        จัดรูปแบบเงินและวันที่แบบ พ.ศ.
```

ไม่มี build step ไม่มี dependency ภายนอก

## ธีมและพื้นหลัง

ทั้งแอปเป็นโทนมืดน้ำเงินเข้ม การ์ดทุกใบเป็นกระจกโปร่งแสง สีทองเป็นสีหลักของแบรนด์
ส่วนเขียวกับแดงสงวนไว้ให้รายรับ รายจ่าย และระดับงบประมาณเท่านั้น ไม่ใช้เป็นสีตกแต่ง

หน้าโฮมมีภาพพื้นหลังเต็มจอพร้อมแอนิเมชันเงินร่วงที่ค่อยๆ ช้าลงจนลอยค้างอยู่บนจอ
ส่วนแสงคือความสว่างของภาพถ่ายเองที่ไล่ขึ้นจากมืด ไม่ได้วาดแสงเพิ่มบน canvas
เพราะแสงสังเคราะห์สามชั้นเดิมตัดกันเองจนเห็นเป็นรอยต่อแข็งๆ ในเมื่อภาพต้นฉบับมีลำแสงอยู่แล้ว
การไล่ความสว่างของภาพจึงให้ผลว่า "ไฟค่อยๆ ติด" ได้ตรงกว่าและเบากว่า

เล่นเต็มความยาวครั้งแรกของแต่ละ session และเล่นสั้นลงเมื่อกลับเข้าหน้าโฮมอีก
เคารพการตั้งค่า `prefers-reduced-motion` และหยุดวาดทันทีเมื่อออกจากหน้าโฮมเพื่อไม่ให้กินแบตเตอรี่

ทุกคู่สีตัวอักษรกับพื้นหลังผ่านเกณฑ์ WCAG AA โดยวัดจากพิกเซลที่เรนเดอร์จริง
รวมภาพถ่าย ชั้นแสง และกระจกทั้งหมด

รวมน้ำหนักไฟล์ภาพทั้งหมด 149 KB

## ยังไม่ได้ทำ

- การซิงก์ข้ามอุปกรณ์แบบอัตโนมัติ (ย้ายไฟล์ CSV เองได้ หรือวางไว้ในโฟลเดอร์ Drive/OneDrive)
- งบประมาณย้อนหลังรายเดือน ตอนนี้เป็นงบเดียวที่ใช้ซ้ำทุกเดือน
- ส่งออกเป็น XLSX
